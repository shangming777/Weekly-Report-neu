# HACI-ProgressReport

1️⃣ 汇报节奏
• 每周五18:00 前交第 1 份周报。
• 内容分 3 栏：
① 代码（前端/后端/数据库/云计算&部署/操作系统等）
② 算法（机器学习/深度学习等）
③ 论文（继续阅读实验室相关方向论文，并说明与代码/算法的结合点）

2️⃣ 格式要求
• 用 Markdown 写，图文结合（代码块、运行截图、架构图、思维导图均可）。
• 图片放仓库内 imgs 文件夹，引用相对路径，保持仓库整洁。

3️⃣ GitHub 提交规范
• 各自构建分支，以stu_姓名形式命名，如“stu_fuchangzeng”。
• 在仓库根目录建 3 个一级文件夹：代码 / 算法 / 论文
• 文件命名：日期-主题.md
例：
代码/2024-08-09-Flask入门实战.md
算法/2024-08-09-Transformer注意力机制.md
论文/2024-08-09-GNN综述阅读笔记.md
